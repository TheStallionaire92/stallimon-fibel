## GitHub-Installation

1. Öffne das Repository `TheStallionaire92/stallimon-fibel`.
2. Gehe auf **Code → Add file → Upload files**.
3. Lade `index.html`, `app.js` und `styles.css` aus diesem Ordner hoch.
4. Bestätige, dass die drei vorhandenen Dateien ersetzt werden.
5. Verwende als Commit-Nachricht `StalliFibel Entdeckungsbilder V1.0.1`.
6. Warte, bis das GitHub-Pages-Deployment einen grünen Haken zeigt.
7. Öffne die StalliFibel und drücke `Strg + F5`.

Cloudflare, Twitch, D1 und Streamer.bot müssen nicht verändert werden.
